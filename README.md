# Свинцовы из Галок и их родня — найденные записи

Открытый указатель архивных записей XIX — середины XX века по нескольким крестьянским семьям Иркутского уезда. Выложен, чтобы следующему исследователю не пришлось повторять ту же работу.

**Семьи и места**

| Семья | Место в документах | Сейчас |
|---|---|---|
| Свинцовы | селение Голковское (д. Голковская), Оёкский приход, Оёкская волость | д. Галки, Иркутский р-н |
| Журавлевы, Ситниковы | Курская деревня (Курское селение), Тугутуйская волость | д. Большая Кура, Эхирит-Булагатский р-н |
| Толстиковы | Харатское селение, Тугутуйская волость | с. Харат |
| Труфановы | Верхне-Кукутская деревня | д. Верхний Кукут |
| Кармадановы | Камойская деревня | д. Комой |

## Файлы

- [`records.csv`](records.csv) — найденные записи: событие, дата (до 1918 — по старому стилю), выписка в написании источника, архивный шифр, ссылка на скан, как проверено.
- [`persons.csv`](persons.csv) — люди и связи между ними с указанием, на каких записях они держатся.
- [`coverage.md`](coverage.md) — какие книги просмотрены, каких **нет** в оцифровке, какие базы проверены без результата.
- [`tree.md`](tree.md) — схема родства.

## Как читать статусы

- **скан проверен визуально** — запись прочитана по изображению страницы;
- **текст страницы** — по автоматической расшифровке страницы, изображение не сверялось;
- **индекс** — только по строке поисковой выдачи;
- связи с пометкой «гипотеза» не доказаны прямой записью.

## Источники

- Метрические книги и исповедные росписи Иркутской духовной консистории — ГА Иркутской области (ГАИО), фонд 50; доступ через [«Яндекс Поиск по архивам»](https://yandex.ru/archive) (нужен вход в аккаунт Яндекса).
- Документы ЦАМО — [«Память народа»](https://pamyat-naroda.ru), «Дорога памяти».

## Чего здесь нет

Сведений о ныне живущих людях и о людях, родившихся после 1925 года. Полных распознанных текстов страниц — только выписки нужных записей; сами сканы смотрите по ссылкам.
